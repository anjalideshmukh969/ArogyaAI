# ArogyaAI 🩺

ArogyaAI is an AI-powered prescription digitizer and medicine safety checker designed to simplify healthcare accessibility and improve patient safety.

The platform allows users to upload prescription images or PDFs, extract medicine information using OCR and AI, and analyze prescriptions for duplicate medicines, missing dosage instructions, and potentially harmful drug interactions.

Built using Next.js, FastAPI, and AI-powered text analysis, ArogyaAI aims to make prescription understanding safer, smarter, and more accessible.
